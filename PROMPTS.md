# 📝 Промпты GPT-4 в DocCompare

## Расположение

**Файл:** `app/services/llm/semantic_analyzer.py`

Все промпты находятся в классе `SemanticAnalyzer`.

---

## 1. Системный промпт

**Метод:** `_get_system_prompt()` (строки 79-116)

**Назначение:** Базовые инструкции для GPT-4 по анализу изменений

**Содержит:**
- Роль: "эксперт по анализу юридических и деловых документов"
- Что игнорировать (косметические изменения)
- На что обращать внимание (семантические изменения)
- **Особый фокус:** удаление/замена конкретной информации
- Формат ответа (JSON)

**Ключевые моменты:**
```
- УДАЛЕНИЕ или ЗАМЕНА конкретной информации (состав комитета, контактные данные)
- ЗАМЕНА детальной информации на обобщённую
- Если удаляется конкретика и заменяется на ссылку - это ВЫСОКОЕ влияние
```

## 2. Промпты для анализа отдельных изменений

**Метод:** `_build_analysis_prompt()` (строки 118-163)

### 2.1 Для добавленных фрагментов

```python
if change_type == "added":
```

**Вопросы к GPT-4:**
1. Является ли добавление семантически значимым?
2. Что конкретно добавлено?
3. Какое влияние это может иметь?

### 2.2 Для удалённых фрагментов

```python
elif change_type == "removed":
```

**Вопросы к GPT-4:**
1. Является ли удаление семантически значимым?
2. **ЧТО КОНКРЕТНО удалено?** (имена, составы, процедуры)
3. Какие последствия?
4. Удалена ли важная информация?

### 2.3 Для изменённых фрагментов

```python
else:  # modified
```

**Вопросы к GPT-4:**
1. Является ли изменение семантически значимым?
2. **ЧТО КОНКРЕТНО изменилось?**
3. **Если удалена конкретика** (состав комитета) и заменена на обобщение - укажи это явно
4. Какое влияние?
5. Есть ли потеря важной информации?

## 3. Промпт для общей сводки

**Метод:** `generate_summary()` (строки 262-350)

**Назначение:** Генерация итоговой сводки по всем изменениям

**Особенности:**

### 3.1 Автопоиск ключевых слов

```python
keywords_to_find = [
    "false complaint",
    "malicious complaint",
    "frivolous complaint",
    "штраф",
    "увольнение"
]
```

Если найдено - добавляет контекст в промпт!

### 3.2 Контекст для GPT-4

Отправляет фрагменты:
- **Начало** документа (2KB)
- **Середина** (2KB)
- **Ключевые фрагменты** (если найдены) - 2KB
- **Конец** (2KB)

**Итого:** ~6-8KB контекста для полного анализа

### 3.3 Инструкции

```
ЗАДАЧА: Проанализируй и укажи ВСЕ ключевые изменения:
1. Что было УДАЛЕНО (составы комитетов, имена, процедуры)
2. Что было ДОБАВЛЕНО (меры наказания, обязательства, процедуры)
3. Что было ИЗМЕНЕНО (замены, модификации)

ОБЯЗАТЕЛЬНО проверь:
- Удаления информации о составе комитетов
- Добавления положений о наказаниях за ложные жалобы
- Изменений в процедурах

СПЕЦИАЛЬНО обрати внимание:
- Ищи упоминания "false complaint", "malicious complaint"
- Ищи штрафы, увольнения за ложные обвинения

Сформулируй в виде МАРКИРОВАННОГО СПИСКА.
```

## Как изменить промпты

### Шаг 1: Откройте файл

```bash
nano app/services/llm/semantic_analyzer.py
# Или в вашем редакторе
```

### Шаг 2: Найдите нужный метод

- `_get_system_prompt()` - строка 79
- `_build_analysis_prompt()` - строка 118
- `generate_summary()` - строка 262

### Шаг 3: Измените текст промпта

Промпты написаны как обычные Python строки.

### Шаг 4: Сохраните и перезапустите

```bash
# Остановить сервер
killall uvicorn

# Запустить с перезагрузкой
cd '/Users/travinov-sv/Library/Mobile Documents/com~apple~CloudDocs/Python Project/DocCompare'
source venv/bin/activate
python -m uvicorn app.main:app --reload
```

При `--reload` изменения применятся автоматически!

## Примеры кастомизации

### Добавить новую категорию

В системном промпте измените:
```python
"category": "dates|obligations|financial|conditions|parties|technical|compliance|other"
```

### Изменить фокус анализа

Добавьте в список внимания:
```python
- Изменения в политике конфиденциальности
- Изменения контактных данных
- Изменения юрисдикции
```

### Добавить новые ключевые слова

В `generate_summary()` дополните:
```python
keywords_to_find = [
    "false complaint",
    "malicious complaint",
    "penalty",          # Новое
    "termination",      # Новое
    "санкция",          # Новое
]
```

GPT-4 вызовы логируются в:

